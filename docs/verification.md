## Проверка через CMake от 17.11.2026

В `Repository::log()` восстановлена строка с явной ошибкой-заглушкой:
после её случайного удаления функция с типом результата `HistoryResult`
не возвращала значение, и компилятор выдавал предупреждение.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --clean-first
ctest --test-dir build --output-on-failure
./build/src/vcslite --help
cmake --install build --config Debug --prefix install
```

Конфигурация и полная пересборка трёх целей завершились успешно,
предупреждений компилятора нет. Оба теста CTest (`cli_help` и
`cli_invalid_command`) пройдены: 2/2. Справка из `build/src/vcslite`
выводится успешно.

Программа установлена в `install/bin/vcslite`. Установленная программа
проверена из отдельной временной папки вне исходников: `--help` завершился
с кодом 0, а `log` — с кодом 1 и явным сообщением о незавершённой реализации.
Файлов в этой временной папке не создано.
